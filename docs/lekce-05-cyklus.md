# Lekce 05 – tabulka životního cyklu

| Scénář | Můj předpoklad | Skutečnost z Logcatu                                                                                        | Proč se to liší                                                                                                                                                                                                                |
|---|----------------|-------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1. Start aplikace z ikony | onCreate -> onStart -> onResume               | onCreate (savedInstanceState = null) onStart onResume                                                       | První vytvoření instance. savedInstanceState je null, protože není z čeho obnovovat.                                                                                                                                           |
| 2. Rotace displeje |      onPause -> onStop -> onDestroy -> onCreate -> onStart -> onResume          | onPause onStop onDestroy (isFinishing = false) onCreate (savedInstanceState = Bundle[…]) onStart onResume   | Změna konfigurace. Stará instance se ruší, systém staví novou s novou konfigurací. isFinishing = false odlišuje rekreaci od zavření uživatelem; nový Bundle je neprázdný, protože systém uložil stav skrz onSaveInstanceState. |
| 3. Stisk Home |    onPause -> onStop            | 	onPause onStop                                                                                             | Aktivita přestala být vidět, instance ale žije dál. Od tohoto okamžiku je proces kandidátem na zabití.                                                                                                                                                                                                                               |
| 4. Návrat do aplikace |     onStart -> onResume           | onRestart onStart onResume                                                                                  |         Návrat ze stavu Stopped. onCreate se nevolá — instance celou dobu existovala. onRestart jen ohlašuje přechod, sám nic neobnovuje.                                                                                                                                                                                                                       |
| 5. Stisk Zpět na MainActivity |     onPause -> onStop -> onDestroy           | onPause onStop                                                                                              |          Nejčastěji chybně předpokládaný řádek. Od Androidu 12 se spouštěcí aktivita na dně zásobníku při Zpět nedokončuje — systém přesune aktivitu i její task na pozadí, stejně jako u Home. Žádný onDestroy. Na nekořenové aktivitě (detail města) by naopak proběhlo onPause → onStop → onDestroy s isFinishing = true.                                                                                                                                                                                                                      |
| 6. adb shell am kill na pozadí + návrat |       onCreate -> onStart -> onResume         | onPause onStop ———— (proces zabit, žádný záznam) onCreate (savedInstanceState = Bundle[…]) onStart onResume |      Zabití procesu. onDestroy se nezavolá vůbec — callback by musel běžet v procesu, který už neexistuje. Po návratu systém obnoví aktivitu z uloženého stavu, takže savedInstanceState je neprázdný, i když jde o nový proces. ViewModel tuto situaci nepřežije.                                                                                                                                                                                                                          |
